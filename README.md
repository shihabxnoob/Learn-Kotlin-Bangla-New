# Kotlin Shikhi
বাংলায় Kotlin শেখার প্ল্যাটফর্ম। বর্তমান scope: শুধু Homepage।

```bash
npm install && npm run dev   # http://localhost:4321
npm run build                # static output -> dist/
```
Deploy: Vercel/Cloudflare Pages-এ repo connect করুন (build: `npm run build`, output: `dist`)।

Roadmap বদলাতে `src/data/roadmap.ts`, রং/ফন্ট বদলাতে `src/styles/tokens.css`।
